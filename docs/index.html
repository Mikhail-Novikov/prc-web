Переход c PERCo-S-20 на PERCo-Web

Почему стоит перейти на PERCo-Web?

1

Во-первых, это выгодно

Бесплатный базовый модуль и пробный доступ на 60 дней

Бесплатный модуль PERCo-Web «Базовый пакет ПО» позволяет организовать контроль доступа на предприятии со штатом до 100 сотрудников.

Рабочие места без ограничений

Безлимитное количество рабочих мест для операторов, подключаемых устройств и идентификаторов.

Бесплатное обучение сотрудников до 100 сотрудников

Мы проводим бесплатное обучение. Семинары PERCo (очные и онлайн) хранятся в открытом доступе.

2

Простое решение для быстрого перехода

Специальный конвертер базы данных

Вся информация о настройках оборудования, сотрудниках и их доступе автоматически передается из системы S-20 с помощью специального конвертера базы данных.

Поддержка новых линеек оборудования PERCo

Программное обеспечение обеспечивает поддержку оборудования с улучшенными характеристиками.

Множество вариантов идентификации

Различные способы идентификации (биометрические данные, карты доступа, штрихкоды, номера или сочетания ГРНЗ и др.)

3

Удобно для разных пользователей

Администратору системы

  1. Соответствие стандартам

    Программное обеспечение входит в реестр отечественного ПО и работает на ОС, входящих в этот реестр.

  2. Совместимость с Linux

    Установка сервера на Linux и работа с 1С на Linux системах.

  3. Бесплатный открытый API

    За счет поддержки API-интерфейса система контроля доступа легко интегрируется со сторонними приложениями, в том числе с системами управления предприятием — CRM- и ERP-системами.

  4. Больше возможностей с помощью Keycloak

    Синхронизация операторов через Keycloak дает больше преимуществ чем AD.

  5. Защита персональных данных

    Возможность запрета передачи персональных данных (ФИО) в контроллер для обеспечения безопасности информации.

Службе безопасности

  1. Оперативный мониторинг

    Организация рабочего места на базе планшета или смартфона.

  2. Гибкая система реакций на события

    Сообщения можно получать через Telegram, СМС и e-mail, в том числе о возникновении нештатных ситуаций.

  3. Дополнительные способы идентификации

    Настройка дополнительной идентификации по графическим и текстовым данным в модуле «Верификация».

  4. Подключение к системам видеонаблюдения и охранно-пожарной сигнализации

    Интеграция с ОПС «Рубеж» и «Интеллект Х» помимо TRASSIR и АРМ «Орион Про».

  5. Интеграции с алкотестерами

    Подключение к системам «Алкорамка» и «Алкобарьер».

  6. Интеграция с металлодетектером

    В случае превышения пороговых значений включается автоматическая блокировка считывателя.

Процедура миграции

  1. Проверяете совместимость оборудования с системой PERCo-Web.
  2. Обновите прошивку оборудования на всех совместимых устройствах до актуальной версии. Если ваше устройство отсутствует, то проверьте архив.
  3. Установите систему PERCo-Web.
  4. Перенесите информацию из базы данных PERCo-S-20 в базу данных PERCo-Web с помощью Конвертера базы данных.
  5. В течение 60-ти дневного периода оцените функционал и состав модулей для приобретения лицензии.

Конвертер базы данных

При переносе данных из PERCo-S-20 в PERCo-Web автоматически активируется ознакомительный режим лицензий «Стандартный пакет ПО» и  «Учет рабочего времени». Вся информация импортируются одним файлом, который включает в себя:

  • Список устройств с параметрами;
  • Общие настройки системы, в том числе конфигурация MIFARE;
  • Структура помещений с привязанными устройствами;
  • Списки сотрудников и посетителей с учетными данными;
  • Справочник оправдательных документов;
  • Список уволенных сотрудников и события за последние 12 месяцев.
