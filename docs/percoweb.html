Переход с PERCo-S-20 на PERCo-Web

Для пользователей системы PERCo-S-20 реализован конвертер баз данных для удобного перехода к работе с системой PERCo-Web.

Вся информация о настройках оборудования, сотрудниках, посетителях и их доступе, графиках работы и событиях системы за последние 12 месяцев автоматически переносится из системы PERCo-S-20 с помощью специального конвертера.

Данные импортируются одним массивом, при этом в PERCo-Web автоматически активируется ознакомительный режим лицензий «Стандартный пакет ПО» и «Учет рабочего времени». Полный список импортируемых данных представлен в документации на конвертер.
